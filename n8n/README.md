# n8n Workflows

Four workflows that handle Google Sheets sync, status updates, error notifications, and daily summaries.

## Prerequisites

1. **n8n running** (Docker):
   ```bash
   docker run -d --name n8n --restart unless-stopped \
     -p 5678:5678 \
     -v n8n_data:/home/node/.n8n \
     n8nio/n8n
   ```

2. **Google Sheets OAuth2** configured in n8n:
   - Go to http://localhost:5678 → Credentials → Add → Google Sheets OAuth2
   - Follow the OAuth flow with your Google account
   - Note the credential ID

3. **SMTP credentials** (for email notifications):
   - Credentials → Add → SMTP
   - Configure with your email provider (Gmail, etc.)

4. **Environment variables** set in n8n:
   - Go to Settings → Variables (or set in Docker env)
   - `GOOGLE_SHEET_ID` — Your Google Sheets document ID (from the URL)
   - `NOTIFICATION_EMAIL` — Email address for alerts and summaries

## Google Sheets Setup

Create a Google Sheet with a tab named **"Jobs"** and these columns:

| Column | Description |
|--------|-------------|
| `id` | UUID (auto-generated by sync workflow) |
| `job_url` | Direct link to job application |
| `company` | Company name |
| `job_title` | Position title |
| `location` | City/state or "Remote" |
| `portal_type` | Auto-detected: greenhouse, workday, lever, linkedin |
| `priority` | high / medium / low |
| `status` | new / applied / failed / skipped |
| `date_added` | When row was added |
| `date_applied` | Auto-filled on submission |
| `notes` | Optional notes |
| `error_log` | Auto-filled on failure |

Add jobs by setting `status = new` and filling in `job_url`, `company`, `job_title`.

## Importing Workflows

1. Open n8n at http://localhost:5678
2. For each workflow JSON file:
   - Click **Add Workflow** → **Import from File**
   - Select the JSON file from `n8n/workflows/`
   - Update credential references (click each Google Sheets / SMTP node)
   - **Activate** the workflow

## Workflows

### 1. Sync Jobs (`sync-jobs.json`)

**Trigger:** Every 5 minutes

**Flow:**
1. Read rows from Google Sheets where `status = "new"`
2. Deduplicate by `job_url` (prevents duplicate processing)
3. Generate UUID for rows missing an `id`, auto-detect `portal_type` from URL
4. Write generated IDs back to the Sheet
5. POST jobs to FastAPI at `http://host.docker.internal:8000/api/webhooks/jobs-sync`

**Note:** Uses `host.docker.internal` to reach FastAPI running on the host. On Linux, you may need to add `--add-host=host.docker.internal:host-gateway` to your Docker run command, or replace with `http://172.17.0.1:8000`.

### 2. Update Status (`update-status.json`)

**Trigger:** Webhook at `/webhook/job-status-update`

**Receives:**
```json
{
  "id": "uuid-of-job",
  "status": "applied",
  "date_applied": "2026-02-19",
  "error_log": ""
}
```

**Flow:** Updates the matching row in Google Sheets by `id`.

**Called by:** FastAPI's n8n client (`backend/n8n_client.py`) after approve/skip/fail.

### 3. Error Notification (`error-notification.json`)

**Trigger:** Webhook at `/webhook/job-failed`

**Receives:**
```json
{
  "job_url": "https://...",
  "company": "TechCorp",
  "error": "Form submission timeout",
  "failure_count": 3
}
```

**Flow:**
- If `failure_count >= 3`: Send alert email ("Automation paused")
- Otherwise: Log and respond OK

### 4. Daily Summary (`daily-summary.json`)

**Trigger:** 6:00 PM daily (cron)

**Flow:**
1. Read all rows from Google Sheets
2. Count by status (today's activity + all-time)
3. Send HTML summary email with stats table

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Workflows don't trigger | Make sure they're **activated** (toggle in top-right) |
| Google Sheets auth fails | Re-authenticate OAuth in Credentials |
| FastAPI unreachable from n8n | Check `host.docker.internal` resolves. On Linux: use `172.17.0.1` or `--add-host` |
| Webhook URL unknown | After activating, click the Webhook node → "Test URL" shows the full URL |
| Email not sending | Verify SMTP credentials (port, TLS, app password for Gmail) |
| n8n container stops | `docker logs n8n` to check errors, `docker restart n8n` to recover |

## Testing

1. **Sync Jobs:** Add a row to Google Sheets with `status = new`, wait 5 minutes (or manually execute the workflow in n8n)
2. **Update Status:** Use curl: `curl -X POST http://localhost:5678/webhook/job-status-update -H "Content-Type: application/json" -d '{"id":"test","status":"applied"}'`
3. **Error Notification:** `curl -X POST http://localhost:5678/webhook/job-failed -H "Content-Type: application/json" -d '{"company":"Test","failure_count":3,"error":"test"}'`
4. **Daily Summary:** Manually execute in n8n UI
